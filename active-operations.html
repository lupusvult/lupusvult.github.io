Active Operations

The projects I am currently working on, maintaining, and managing.

Gigaslice Games

Gigaslice Games is the shelter for my personal passion projects and the collaborative projects I manage. Not every project I participate in falls under the Gigaslice Games banner. Having a sole operator keeps things less chaotic and ensures everything stays in line.

It serves as an enforcer of a strict set of rules for projects released under its banner to keep the quality standardized and annoyances of the mobile game industry out. More information about these rules and the projects published by Gigaslice Games can be found on its website.

Tribal Studio

Tribal Studio is a virtual studio that I co-own with a childhood friend of mine. We needed a name for our collaborative projects, and Tribal Studio felt like a natural fit for how we operate. Currently, we're working on small yet ambitious mobile game projects that can be completed within a short timeframe to test the waters.

I design and document our projects, as well as create the visuals, while my friend handles the coding and all the behind-the-scenes work. We also maintain an idea pool and develop prototypes from it. Any mechanics or features we like can make their way into our main games, we assemble our own little Frankensteins.

Unnamed Project

This project actually has a name, but it isn't public yet and won't be for quite some time. It's a series of three interconnected games, but I'll first release a Game Boy Color game that carries the same branding while remaining separate from the main games.

The main games will be arcade, platformer, and dungeon crawler with RPG elements, in that exact order. These genre choices have a reason behind them, which I'll explain later. The Game Boy Color game isn't actually necessary for the series, I'm making it simply because I want to play a fast-paced platformer on the original hardware.

It'll take quite a bit more time to finish because I want to design all three games in detail before I start building them. This is so I can keep the interfaces, art style, some mechanics, and humor consistent between them. Also, I only work on this project with whatever time I have left on my hands after real life and Tribal Studio's projects.
