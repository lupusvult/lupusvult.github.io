Active Operations

A list of projects I am currently working on, maintaining, and managing.

Gigaslice Games

Gigaslice Games is the shelter for my personal passion projects and the collaborative projects I manage. Not every project I participate in falls under the Gigaslice Games banner. Having a sole operator keeps things less chaotic and makes it easier to maintain a consistent vision.

It serves as an enforcer of a strict set of rules for projects released under its banner to keep the quality standardized and annoyances of the mobile game industry out. More information about these rules and the projects published by Gigaslice Games can be found on its website.

Tribal Studio

Tribal Studio is a virtual studio that I co-own with a childhood friend of mine. We needed a name for our collaborative projects, and Tribal Studio felt like a natural fit for how we operate. Currently, we're working on small yet ambitious mobile game projects that can be completed within a short timeframe.

I design and document our projects, as well as create the visuals, while my friend handles the coding and the technical work behind the scenes. We also maintain an idea pool and develop prototypes from it. They give us a space to experiment with and refine new concepts, and any mechanics or features we like can make their way into our main games.

Project: Redacted

This project actually has a name, but it isn't public yet and won't be for quite some time. It's a series of three games that complement each other, each in a different genre that I enjoy. I'll first release a Game Boy Color game that carries the same branding while remaining separate from the main series.

The Game Boy Color game isn't actually necessary for the main series, I'm making it simply because I want to play a fast-paced precision platformer on the original hardware.

It'll take quite a bit of time to finish because I want to design all three games in perfect detail before I start building them. This is so I can keep the progression, dialogue, interfaces, and some mechanics consistent across all three games. Also, I only work on this project with whatever time I have left on my hands after real life and Tribal Studio's projects.
